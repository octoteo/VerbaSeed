# Content and Copyright Policy

VerbaSeed separates software from learning content.

## Official repository and registry

The project may distribute or index content only when the project has a clear right to do so, for example:

- original VerbaSeed material;
- public-domain material;
- material under an explicit compatible open license;
- metadata or adapters that do not reproduce protected course content.

Commercial textbooks, copyrighted animation episodes, paid course assets and unofficial re-uploads must not be copied into the official repository merely because they are available online.

## User-provided sources

The application may provide import tools for material a user lawfully possesses or can access, including camera images, PDFs, local media, subtitles and user-selected GitHub sources. Import support does not grant redistribution rights.

## Provenance

Course packages should declare source, license, attribution and version information. Unknown provenance is represented as unknown; the software must not invent a permissive license.

## AI-generated transformations

OCR, translation, transcription, summaries and generated exercises are transformations, not automatic proof of redistribution rights. AI-generated course output must retain source provenance and be validated before publication to a public registry.
